**Version 1.0**

- Date: 2026-11-12T04:56:29Z
- Task: [naming-conventions](../tasks/naming-conventions.md)
- Role: coordinator
- Topic: delivery naming
- Status: confirmed
- Observation: The baseline describes PR body presentation but does not define
  a shared branch, issue-title or PR-title grammar. Recent branch names use both
  `codex/` and `intake/`; recent issue/PR titles are plain summaries.
- Evidence: Baseline `d48e0e4`, delivery specification section 4.1 and PR template;
  read-only GitHub metadata for PRs 96, 98, 101–103 and issues 99–100 observed
  during this task. This is a bounded sample, not a repository-wide inventory.
- Suggested action: Define one canonical grammar with linked instruction/template
  reminders and fresh policy review; preserve existing names and distinguish
  naming conventions from automated enforcement and publication authority.
