## Alternatives and analytic opportunity

Let `Q=2*O-1`, `H=Z*Y*(X//2+1)` and `b=16*Q*H` bytes. Whole prepared payload is `Bq=T*D*b`. These are logical array bytes, excluding containers, alignment, finite/hash buffers, diagnostics, FFT/native workspaces, allocator retention and OS/caller headroom.

| Representation | Removable source unit after last consumer | T>1 | T=1,D>1 |
| --- | --- | --- | --- |
| Existing one q ndarray | Entire `T*D*b` root | Time views pin every time | All directions remain pinned |
| Independent time roots | `D*b` | Can release a time after its filter and aliases end, before assembly if wired inside the call | No direction release; time-only fragmentation leaves source working set unchanged during filtering |
| **Selected independent (t,d) roots** | `b` | Release directions within each current time, then empty time metadata | Release completed directions while remaining directions still filter; all current-time q can leave before assembly |

With k successfully consumed pairs in workflow order, the proposed ordinary successful-path source payload is `(T*D-k)*b`, provided all aliases end. This is an upper bound on retained q payload under the specified protocol, not an RSS curve or reduction of the whole execution peak. The whole current-time filtered destination `D*b` is allocated **before any source release** and remains through filtering/assembly/result finishing. At the first filter allocation, all `T*D*b` source bytes still exist; fragmentation does not lower that allocated-payload overlap. All q also coexist during preparation and estimation. Raw snapshots, optional off q, full diagnostics when requested, already retained caller inputs, layout outputs and native workspaces remain separate mandatory terms. Earlier peaks can dominate any later benefit.

Pair owners add metadata/allocations and private access adaptation. Time owners are simpler but fail the explicit T1/multiple-direction release objective; choosing pairs is justified by actual coefficient locality, not an unproved performance ranking. No streaming scientific pipeline, spatial tiling, raw replay, precision change, filter/assembly fusion or #120 assembly redesign is proposed.

## Private representation and stage schedule

Proposed names are descriptive, not implemented/exported API. Each live slot owns its own C-order `(Q,Z,Y,X//2+1)` complex128 allocation. It is neither a view into a full q parent nor an array-coercible facade; no hidden stack/concatenate or second all-block owner tuple is allowed.

## Global validity and failure equivalence

Preserve logical aggregate validity even though physical roots are smaller. Preparation must still check complete qshape, diagnostic/off/header extents before raw scans/target allocations; downstream must validate the complete logical current-time collection before any filter release. Preserve signed32 dimensions/counts/indices and actual-width native aggregate bytes, including T/D/P/Z, Q*P, D*O, T*D*Z*P, on/off exposure/header products and output/identity/trace extents. Do not add a new aggregate signed32 bound, revive obsolete byte-only caps or interpret representability as RAM admission (#115 sections23–106).

`modes.validate_downstream_bands:154–220` orders shape/mode/q type-dtype-shape, noise type-dtype-shape, zoom/sampling/scale/source identity, signed/output/native extents, global q finite, global noise finite, then positive noise. A private block validator substitutes complete slot metadata and all-block finite scanning at those same barriers; it does not scan one block before another block's metadata, or noise before completion of q scanning. Finite scans have no numerical side effects; chunking their Boolean predicate preserves acceptance/rejection and the existing aggregate label, with no new per-block t/d error coordinates. Any allocation-dependent finite-buffer difference stays a resource difference. Scientific `t,d` locals and whitelisted traceback extraction must retain original available context; scan helpers must not introduce misleading `t,d` locals.

Estimation validates flags and transfer before bands (`1100–1115`); known reconstruction validates bands before transfer/options (`1017–1097`). Keep those distinct priorities. Final preparation q/noise/diagnostic, whole-time filtered, coordinate, embedded/inverse/assembled-image and returned-array finite checks retain their relative operation order. Do not check off q early to free it, insert per-direction filtered finite checks, skip zero-weight transfer stencil checks, or convert later-time failure to partial success. Details are in [lifetime map](lifetime-map.md).

RM84 section3:177–182 explicitly preserves MemoryError/interruption and causes/context while allowing allocation-dependent success to differ. Independent allocations need not reproduce one monolithic allocation's resource-success threshold; neither exact failure at the same allocation ordinal nor identical interruption instruction is promised. Preserve actual propagation/translation: direct acquisition/known operations keep causes; workflow unwraps allocation causes to MemoryError and otherwise retains stage and available indices (`result.py:85–144`). Exceptions can retain frames/owners and previously completed filtered regions; no immediate failure-path reclamation guarantee is added. An implementation unable to retain these categories, numerical precedence, or context must stop for a precise equivalence finding rather than invent a new failure policy.

## Identity and public compatibility

The canonical identity is one record: name `prepared_quadratures`, whole logical shape, normalized dtype `<c16`, one SHA256 over the logical C-order little-endian element byte stream. Shape/name/dtype are **separate metadata**; no literal header bytes enter the digest (CE07:406–418; `identity.py:160–176`). Update a single digest in increasing t,d,q,z,y,half-x order. Independent pair payloads form adjacent intervals of that byte stream; concatenating digest inputs through successive updates equals hashing those byte intervals as one stream. No block-digest composition, list serialization, separators, padding, stack or whole normalized duplicate is permitted.

Private roots are C-order native complex128; a bounded byte iterator normalizes multi-byte components to little endian where necessary without arithmetic conversion. For strided or nonnative-endian values within existing public identity domains, enumerate bounded logical C-order chunks and reverse bytes within each real/imaginary component as appropriate, preserving component order and signed-zero bits. Chunk boundaries add no bytes and should fall on complete elements; no rounding or real/imaginary exchange is allowed. This byte-specification argument is independent of product self-agreement; later blind tests need independent explicit byte patterns. Existing public ndarray identity paths remain compatible. Off q is still finite-validated but has no compact off-q identity; raw/selected-off and all other projection identities remain unchanged.

Public CE02 PreparedBands and CE06 AcquisitionBands q/noise stay owned/writable; diagnostics stay independent/read-only. Direct estimator/known reconstruction continue independent snapshots of valid caller-modified, strided or read-only records. PreparedBands noise `(D,O)` and AcquisitionBands noise `(T,D,O)` remain distinct. Callers may retain every input; there is no caller deletion/GC requirement or new concurrent-mutation promise. Full workflow keeps bands/off/complete overlaps/known records/layout. Default entries, schemas, values, signed zeros and discrete decisions remain exact on the pinned environment.
