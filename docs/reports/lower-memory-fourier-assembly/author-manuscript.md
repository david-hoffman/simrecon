# Lower-memory Fourier assembly: exact-compatibility no-go

The tested destructive inverse of private disposable Fourier padding does not preserve the existing exact result. In the finite W2d case, the baseline and retained-padding control agree while the overwrite candidate produces different complete image bytes, in both the literal-spectrum lane and the genuine public-derived-input lane. This report therefore hands off **one no-go for this candidate on the tested source, SciPy interface, backend and environment**. Do not implement this candidate as an exact-preserving lifetime change under the existing contract.

This is a metadata-corrected design-study manuscript awaiting fresh independent assessment of the affected portability changes. Original SCI3 assessed the original frozen manuscript; that historical verdict does not accept this revision. ROOT accepted the independent counterexample classification and released report preparation in [its exact application](evidence/review/ROOT-SCI2-counterexample-acceptance-and-report-release-1.json). That classification is distinct from acceptance of this corrected manuscript, final verification, readiness review, PR or CI. No product change, tolerance, alternative algorithm, backend substitution, new precision profile or public API change is delivered.

Memory and latency were not measured for this candidate. The resident floor, saving, repeat variation, retained-padding resource effect and full-volume feasibility are unmeasured. The result is the contract's “changes exact results” branch, not a measured-resource no-go or a conclusion about all overwrite strategies.

The [CE04](../../contracts/c-equivalence-known-parameters-v1.md), [CE06 §9.2](../../contracts/c-equivalence-acquisition-modes-v1.md), [memory](../../contracts/reconstruction-memory-v1.md) and [wide-allocation](../../contracts/wide-allocation-domain-v1.md) boundaries remain intact:

- Embed the full native integer grid into the enlarged grid without a coordinate shift. Keep even Nyquist positive and unsplit. For negative x, reflect all native axes and conjugate E and O separately before forming E+iO.
- The positive-exponential inverse sum is unnormalized (`norm="forward"`), retaining the upstream preparation scale. Center contributes Re(u); side m contributes `2*Re(u*exp(+2*pi*i*explode*m*(kx*x+ky*y)))`, with coordinates in micrometres and carriers in cycles per micrometre.
- Native 2D transforms plane zero only, including axial enlargement; later planes remain initialized zero. Full 3D uses the full enlarged inverse. Centered lateral coordinate labels do not shift the inverse array.
- Preserve time/direction/order traversal, omit-center selection, phase evaluation, signed accumulation, negative and zero values, and finite signed/fractional/negative explode. Preserve float64/complex128 storage, caller independence and public result/summary/debug semantics.
- Preserve the sequence: embedded-coefficient finite check, inverse, inverse finite check, side phase and its finite check, unchanged exponential/product/real/factor-two addition, image finite check. The existing operation wrapper preserves reconstruction errors and wraps other operation exceptions with causes. Source preservation is not an observed general failure guarantee.

A pure lifetime change requires complete same-environment byte agreement, including signed-zero bits. Ideal real arithmetic alone cannot establish that stronger condition. Representation-valid wide allocation bounds likewise imply no RAM or backend-execution guarantee.

These equations follow directly by substituting the sparse modes into the positive inverse sum. In W2d, the six fixed (h,i,j) samples (0,0,0), (2,0,0), (4,0,0), (6,0,0), (0,1,0), (0,2,0) have ideal values 2, −4, −2, 4, 1+2√3, −1+2√3. The symbolic √3 references are exact algebraic values. The qualifier reports exact dyadic residuals for rational references and fixed open rational reference brackets (13/3,9/2), (7/3,5/2) for the algebraic values. These brackets are reference enclosures, not output tolerances. Neither the floating direct-sum helper nor the native FFT/exponential has a qualified forward-error bound here.

Two lanes preserve the distinction between equations and public provenance. The literal lane passes fixed filtered coefficients to baseline/candidate/control in that order. `_same` compares shape, dtype and complete `tobytes()` values in memory. Independently, the identity helper records shape, little-endian dtype and SHA-256 of canonical contiguous bytes. It does not archive complete arrays.

The public lane uses the actual public `prepare_bands`/`PreparedBands` and `declare_otf`/`reconstruct_known` path in pinned [c_known_fixture.py](../../../tests/c_known_fixture.py), SHA `5e80aafb44b59ae9d45592181b72d62ce03dd7f49f146313294a16c73a2d89a6`. `blank` prepares float32 zero raw input and the qualifier changes the permitted finite writable used quadratures. Explicit settings include wavelength 520 nm, numerical aperture 0.8, immersion index 1.33, Wiener 0.5, no singularity suppression, no center dampening, no kz0 omission and no output taper; supplied modulation is zero. The radial OTF table has spacing 0.25 cycles/µm and is constant for W2a/b/d; W1/W2c use the specified nonconstant dyadic table. This is the used-record public domain, without an assertion that mutated quadratures replay raw pixels.

Y1 filtering has empty traversal. W2d uses the legitimate odd-Y center retained row: the native y=−1 row is omitted by the center filtering traversal and its specified coefficient survives. Its public-derived filtered bytes and metadata actually correspond to the literal witness. The public lane takes the returned filtered arrays, carriers, coordinates and resolved grid and calls the three actual kernels on those values; it does not replace differing public inputs with literal ones. All seven cases report true filtered-byte/value correspondence, metadata/reference applicability and unchanged literal/public kernel-input flags. ## Live-set motivation and unmeasured limits

Source inspection explains the hypothesis without estimating RSS. Let `Vo=Zo*Yo*Xo`, `A=Yo*Xo`, and `H=Z*Y*(X//2+1)`. The following are payload formulas for float64/complex128 arrays, not measurements, allocation traces or a summed resident floor.

| Family | Payload/alias and source-derived interval |
| --- | --- |
| Filtered inputs and image | Filtered quadratures have `16*T*D*(2O−1)*H` bytes; a time view may retain the whole owner. Image has `8*T*Vo` bytes throughout assembly. Public callers and prior outputs may coexist. |
| Padding and inverse | Each complex enlarged volume has `16*Vo` bytes. Baseline padding and returned inverse coexist during the call; padding is deleted before phase. Candidate permits destruction but no executed W5 establishes sharing or allocation behavior. Deleting a name does not prove physical release. |
| Native 2D | Baseline additionally initializes a full complex zero volume and assigns a plane inverse. The plane transform's returned storage may coexist during assignment. Candidate reuses initialized private padding. No allocation/RSS reduction was measured. |
| Phase and exponential | Real phase is `8*A`; imaginary phase and exponential are complex lateral `16*A` families, broadcast over z. Phase survives its last use into the next loop until replacement/return; old/new phase can overlap during evaluation. Exact temporary release is unobserved. |
| Product, view and scaling | Spatial times ramp creates complex `16*Vo`; `.real` shares that backing; factor two produces real `8*Vo`. Spatial and image coexist through addition. These formulas do not justify rearranging arithmetic. |
| Native workspace/allocator | Unknown internal FFT precision, workspace, copy behavior, finite-check temporaries, allocator retention and OS accounting. Pointer equality, shares_memory or output dtype would not prove their absence. W5 was stopped. |
