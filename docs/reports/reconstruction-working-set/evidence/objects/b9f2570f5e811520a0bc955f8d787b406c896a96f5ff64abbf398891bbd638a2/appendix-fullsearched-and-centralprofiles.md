## Profiling scope, liveness and controls

The scalar observer patches only workflow.reconstruct's imported workflow_stage
name; independently imported contexts and uninstrumented call regions are
not covered. Native T1 profile records have declaration, preparation,
estimation, reconstruction(time0), result, enter/exit in the qualified order.
Records contain stage/time_index/edge/monotonic_ns and target cumulative
ru_maxrss_native_KiB. The actual60 events are retained records, not an
allocation attribution [R24,R28,R29]. Event timestamps and cumulative usage
include hook work, have uninstrumented gaps, and cannot be summed into pure
math time or stage contributions.

The hook retains scalar dictionaries, not arrays, and does not inspect
numerical caller frames. Active generator/context frames, closures, kwargs,
dict/list growth and failure traceback handling can still retain locals or
allocate. Original workflow error translation inspects traceback frames/
f_locals in both modes. Input/result hashing, finite checks and retained-
payload traversal transiently hold arrays/iterators/memoryviews already
rooted by case/result. Internal traversal IDs are not returned: metadata
has counts/byte estimates/shapes/dtypes/paths, no object IDs or array objects.
No per-stage file flush occurs; events serialize with final child JSON.
Parent sampling/logging and JSON/pipe/disk/cache effects prevent an isolated
causal observer-overhead interpretation.

Source facts, not measured contributors, remain distinct [R28,R29]. Prepared
all-T q stays through the entire reconstruction loop until bands=None before
final concatenation. Per-time filtered intermediates have separate lifetimes;
views are not another q allocation. Full searched mode retains nine overlap
records/27 backings and dynamic copied search trace arrays/scalars; compact

do not close FFT/native workspaces, allocator/cache/header/trace costs or
provide a whole-process bound.
