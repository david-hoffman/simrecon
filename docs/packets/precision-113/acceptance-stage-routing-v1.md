## Source of the stage distinction

Contract §6 says: "Before acceptance require matched real execution evidence from
the resulting runtime, not standalone kernels." The same section assigns that
resulting-runtime evidence to a separate later nonblind author and says:
"After grant and frozen B checkpoint, C's focused checks, complete exact-candidate
Ubuntu make verify ... then fresh D acceptance remain required."

the matched resulting-runtime requirement belongs to final scientific/product
acceptance. It cannot mean that the not-yet-authored C runtime must already be
proven before B can accept a valid independent test checkpoint. No scientific
requirement is removed by identifying its actual stage. If a separate precise
